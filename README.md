# Wenkang Zhang's Academic Website

This website is based on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template.

Live website: <https://cloundkk.github.io>

## Main Content

- Site configuration: `_config.yml`
- Navigation: `_data/navigation.yml`
- Homepage: `_pages/about.md`
- Publications and patents: `_pages/publications.md`
- Research projects: `_pages/projects.md`
- Curriculum vitae: `_pages/cv.md`
- Custom styles: `assets/css/main.scss`

GitHub Pages automatically builds and publishes the website from the `main` branch.
