# 张文康个人学术主页

基于 [Academic Pages](https://github.com/academicpages/academicpages.github.io) 构建，目标地址：

<https://cloundkk.github.io>

## 发布到 GitHub Pages

1. 在 GitHub 创建公开仓库 `cloundkk.github.io`。
2. 将本目录全部文件提交并推送到仓库的 `master` 或 `main` 分支。
3. 在仓库 `Settings > Pages` 中将部署来源设为 **GitHub Actions**。
4. 等待部署完成后访问上方网址。

## 主要内容位置

- 站点配置：`_config.yml`
- 顶部导航：`_data/navigation.yml`
- 首页：`_pages/about.md`
- 论文与专利：`_pages/publications.md`
- 科研项目：`_pages/projects.md`
- 简历：`_pages/cv.md`
- 自定义样式：`assets/css/main.scss`

## 后续建议

- 在 `_config.yml` 中补充 Google Scholar、ORCID、LinkedIn 等链接。
- 如需公开 PDF 简历，建议先制作去除手机号、年龄、民族和政治面貌的公开版本，再放入 `files/`。
- 可将 GitHub 头像替换为本地正式证件照，并将图片保存至 `images/`。
